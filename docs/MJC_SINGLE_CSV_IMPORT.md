# 명지전문대 단일 CSV 가져오기

변환 도구가 생성한 UTF-8 CSV를 명지전문대 성적 파일에 선택한다. 최상위 열은 `sheet`,
`row_kind`, `values_json`이며, 원본 시트 헤더와 데이터 행의 셀 값을 순서대로 담는다.
일반 CSV 파일이나 엑셀에서 다시 저장해 앞부분만 남은 파일을 이 형식으로 취급하지 않는다.
현재 단일 CSV 크기 한도는 1GiB이고, 업로드 후 백그라운드에서 처리한다.

지원자, 학생부, 검정고시 및 기타 원자료의 행 구성과 연결을 확인하고 기존 명지 ZIP과 동일한
계산 입력·미산출 판정 경로로 전달한다. 과목이 `raw_student_subjects_2` 등으로 나뉘면
헤더가 일치하는지 확인하고 이어 붙인다. 저장 전 검사가 실패하면 기존 저장본을 유지한다.

변환된 CSV에는 ZIP의 `execution.csv`, `file-index.csv`와 원본 part 번호가 없다.
따라서 파일 자체로 원본의 대학·학년도, 업로드 이전의 원본 전체 포함 여부, 파일별 전체 행 수와
원래 part를 검증하거나 복구할 수 없다. 지원자별 연결과 명시된 건수는 검사하지만, 전체 지원자
집합이 누락되지 않았다는 증거를 대신할 수는 없다. 화면에서 선택한 대학·학년도와 원본 구성을
사용자가 확인해야 한다. part를 임의로 표시하지 않는다. 완전성 증빙이 필요한 업무에서는 원본
명세를 보유한 기존 ZIP을 사용한다.

단일 CSV는 ZIP/XLSX보다 커질 수 있으며, 대용량 데이터 읽기·DB 저장·성적 계산까지 빠르다는
보장은 없다. 프록시나 별도 서버의 요청 본문 제한은 운영 환경에서 별도로 확인한다.
