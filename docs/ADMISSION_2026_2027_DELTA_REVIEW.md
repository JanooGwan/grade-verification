# 경복대·명지전문대·한신대 2027 성적검증 변경 검토

검토일: 2026-10-15. 기존 일치 검증을 완료한 2026 계산을 기준으로 2027 정량 규칙을 비교했다. 삼육대 2027 규칙은 변경 대상에 포함하지 않았다.

경복대의 등급 환산표, 평균등급 소수 첫째 자리 절사, 진로선택 A/B/C→1/3/5 환산, Z값 변환, 검정고시 필수과목 등급화, 학기 동률 시 이수단위·최근 학기 기준은 유지한다. 2001년 이전 졸업자의 반영 범위 예외도 2027 계산에 연결한다. 학과명 변경에 따라 물리치료학과를 기존 보건계열 그룹에 연결한다. 2027 정시 항공서비스·준오헤어디자인은 학생부 100% 그룹에 연결하고 면접 대기 상태를 만들지 않는다. 공식 2027 반영비율 표에 없는 정시 고른기회2 규칙은 새로 게시하지 않는다.

명지전문대의 학부 신설·학과명 변경은 정량 산식 변경과 구분한다. 실제 모집학과는 원천 지원정보 가져오기를 통해 연결하며 모집정원 자체는 이 작업에서 관리하지 않는다.

## 한신대 2026 최소 과목 수에 대한 확인

2026 보관본 PDF 36쪽에도 ‘학생부 성적의 반영과목수가 부족한 자는 지원자격 미달 처리합니다’라는 문구가 있다. 따라서 과거 문서의 ‘2026에는 자격 제한 없음’ 설명은 정정했다.

사용자는 이번 작업에서 **2026 계산을 유지하고 2027에만 명시된 12과목 기준을 적용**하도록 확인했다. 기존 2026 `minimumCourseCount=0`을 보존했다. 이는 2026 모집요강에 과목 수 제한이 없다는 해석이 아니다. 2027 `minimumCourseCount=12`와 체육실기 배점 변경은 V29·V30에 이미 구현되어 있으므로 같은 규칙을 중복 생성하지 않았다.

## 명지전문대 피드백 반영

1. 미기재 학년·학기의 9등급 보정은 평균점수 합산 단계에서 처리한다. 가상 과목·가상 이수단위를 생성하지 않는다.
2. 반영 과목 수·반영 이수단위·과목 상세는 실제 원천 과목만 집계한다. 누락 학기의 30%·30%·40% 비율과 최하위 9등급 점수는 유지한다. 전체 원천 재실행에서 기존 최종점수와 차이가 없었다.
3. 우수학기 평균등급이 같으면 기존의 2학기 우선 선택을 유지한다. 이 기준은 시스템의 일관된 표기 선택이며 모집요강이 새로 요구한 점수 차이로 해석하지 않는다. 학교의 동률 표시 기준이 별도로 확정되면 그 기준에 맞춘 표기 변경을 별도 처리할 수 있다.
4. `P`, `·`, `이수`, `우수`, `보통`, `미흡`을 숫자 등급과 분리한 `source_grade_text`에 저장하고 저장 검증 JSON·Excel·검증 상세 표시까지 전달한다. 점수 계산용 숫자 등급은 계속 비워 둔다.
5. 지적된 1학년 1학기 17행은 원천에서 모두 이수단위 0이었다. 가져오기가 이 행을 폐기하던 동작을 바꿔 상세에 보존하고 계산에서 제외한다. 같은 원인인 다른 0단위 과목도 보존한다.
6. `32,620 + 4 + 4 = 32,628`이다. 이전 안내의 `32,630`은 잘못이다. 피드백에서 제시한 실제 증가량 32,634행과의 차이를 근거 없는 합산으로 설명하지 않는다. 앞으로 내보낸 행 수와 원천 행 수를 직접 대조한다.

## 변경 파일·적용 방식

- V56: 경복대 2027 규칙 31개를 새 버전으로 게시한다. 2026 규칙을 갱신하지 않는다.
- V57: 명지전문대 2027 규칙 11개를 학생부 배점·학과 유형별로 게시한다. 기존 2027 규칙은 폐기하고 2026 규칙을 보존한다.
- V58: 현재 과목과 원천 스냅샷 테이블에 원천 등급 문자열 칼럼을 추가한다.
- 공통 계산기와 가져오기·내보내기에 2027 연결을 추가하고 원천 보존을 보완했다. 화면에서도 경복대 2027 정량 계산을 지원하며 프리셋을 게시 규칙과 맞췄다.

서버에 코드와 마이그레이션을 적용한 후, 명지전문대는 **원천 재업로드 → 성적검증 재실행 → 새 결과 내보내기**가 필요하다. 과거 저장 JSON과 과거 Excel은 당시의 계산 결과이므로 코드 변경만으로 재작성되지 않는다. 이전 가져오기가 버린 0단위 과목과 비수치 값은 DB에 남아 있지 않아 원천을 다시 읽어야 복원된다.

## 검증 결과

- 명지전문대 2026 실제 원천 15,503명·852,350행을 수정 전 코드와 수정 후 코드로 재실행: 1,000점 기준 산식 점수 차이 0건, 가상 과목 수 정정 대상 26명, 원천 대비 계산 상세 행 수 차이 0건.
- 같은 원천을 2027 규칙에 대입한 비교 시나리오: 2026 수정본 대비 점수 차이 0건. 이는 2027 실제 지원자 성적 대조를 대신하지 않는다.
- 별도 임시 MySQL 8.0에서 Flyway 전체 마이그레이션 및 기존 2026 규칙 보존, 새 2027 게시 규칙과 원천 문자열·0단위 과목의 현재/스냅샷 저장을 확인했다.
- Gradle 실행은 환경의 loopback 연결 오류로 실패했고 IDE 빌드 도구도 공백이 포함된 프로젝트 경로 파싱 오류로 실행되지 않았다. Java 21 직접 컴파일 및 JUnit 전체 실행에서 398건 중 384건 통과, 14건 건너뜀, 실패 0건을 확인했다. Docker가 없어 Testcontainers 테스트는 별도로 실행되지 않았으며 DB 마이그레이션과 바인딩은 위 임시 MySQL에서 확인했다.
- 프런트엔드 `pnpm lint`, `pnpm build`를 실행했다. 빌드는 자식 프로세스 제한을 해제한 실행에서 통과했다.
