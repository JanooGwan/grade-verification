# 삼육대 대용량 원천 Excel 가져오기

## 대상 포맷

`SYU_SOURCE_WORKBOOK_V1`은 삼육대 원천 전달 파일의 다음 시트를 사용한다.

- `학생부 교과 성적`: 입학연도, 수험번호, 학년, 학기, 교과명, 과목명, 이수단위와 성적 정보
- `학생부출결`: 수험번호·학년별 사고 결석, 지각, 조퇴, 결과

현재 전달본의 `지원자 정보` 시트는 교과 성적과 중복된 구조이므로 읽지 않는다. `과목편제코드`는 원천 데이터 확인용이며 현재 가져오기에서는 사용하지 않는다.

## 처리 흐름

1. `POST /api/transcripts/imports/source/syu`가 파일을 최대 200MB까지 임시 저장하고 작업 ID를 반환한다.
2. 단일 전용 실행기에서 작업을 순차 처리해 여러 대용량 파일이 동시에 메모리와 DB를 점유하지 않게 한다.
3. 한 번의 SAX 스캔으로 교과·출결 시트를 함께 읽어 입학연도와 수험번호를 검증한다.
4. 신규 지원자는 이름 `미등록`으로 생성한다. 정확한 학생명과 학교정보는 별도 추가정보 파일 또는 학생 편집 화면에서 보완한다.
5. 교과·출결 시트를 한 번 더 열어 순차 스트리밍하고 5,000행 단위 JDBC 배치 upsert로 저장한다. 진행률은 10,000행 단위로 갱신한다.
6. `student_transcript_import`에 `QUEUED`, `PROCESSING`, `COMPLETED`, `COMPLETED_WITH_ERRORS`, `FAILED` 상태와 진행 건수를 기록한다.
7. 처리가 끝나면 임시 파일을 삭제한다.

화면에서 선택한 모집연도와 파일의 입학연도가 다르면 작업은 `FAILED`로 종료된다. 동일 학생·학년·학기·교과·과목은 기존 자연키 기준으로 갱신되므로 같은 파일을 다시 처리해도 교과 행이 중복 생성되지 않는다.

## 운영상 제한

- 업로드 파일은 `.xlsx`, 최대 200MB다.
- 교과 시트는 최대 1,500,000행까지 처리한다.
- 원천 파일에는 전형·모집단위와 학생명이 없으므로 지원정보 생성과 학생명 확정은 이 작업의 범위가 아니다.
- 애플리케이션 재시작 시 실행 중인 로컬 임시 파일 작업은 자동 재개되지 않는다. 운영 환경에서 재시작 복구가 필요하면 영속 파일 저장소와 작업 재시도 큐를 추가해야 한다.
