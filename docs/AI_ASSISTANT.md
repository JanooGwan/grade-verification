# AI 데이터 도우미 설정

AI 도우미는 Claude에 데이터베이스 접속 권한을 주지 않는다. 서버가 테이블 설명을 읽어 Claude에 후보 선택을 요청하고, 필요한 컬럼 메타데이터만 추가로 제공한다. Claude가 만든 SQL은 서버에서 다시 검증한 뒤 별도의 읽기 전용 계정으로 실행하며, 조회 결과를 근거로 최종 답변을 생성한다.

## 설정 순서

1. `docs/sql/create_ai_readonly_user.sql`을 운영 환경에 맞게 수정해 읽기 전용 계정을 만든다.
2. `.env.example`을 참고해 서버의 안전한 비밀 저장소 또는 로컬 `.env`에 `ANTHROPIC_API_KEY`, `AI_DB_URL`, `AI_DB_USERNAME`, `AI_DB_PASSWORD`를 설정한다.
3. `AI_ASSISTANT_ENABLED=true`로 활성화한다.
4. Flyway를 실행해 최신 테이블 설명 마이그레이션까지 적용한다.

기본 모델은 `claude-haiku-4-5-20251001`이며 `ANTHROPIC_MODEL`로 변경할 수 있다. Claude에는 DB 비밀번호나 접속 문자열이 전달되지 않는다.

질문에 답하기 위해 서버가 조회한 비식별 업무 데이터는 Anthropic API 입력으로 전달된다. 학생·성적·지원·검증 이력 테이블은 AI 조회 허용 목록과 DB 권한에서 제외되며, 허용된 결과도 서버에서 한 번 더 필터링한 뒤 전송한다. 운영 적용 전 조직의 개인정보 처리 기준, Anthropic 계약·데이터 보존 정책, 전송 가능한 데이터 범위를 확인해야 한다.

## 다중 방어선

- 민감정보 관련 질문은 모델 호출 전에 차단한다.
- 입학관리·모집요강·전형·학생부 성적 검증 범위를 벗어난 질문은 모델과 DB 호출 전에 차단한다.
- Claude의 테이블 선택·SQL 작성·최종 답변 시스템 프롬프트에도 동일한 주제 범위를 명시한다.
- 모델에는 승인된 비민감 테이블의 설명과 필요한 컬럼 메타데이터만 전달한다.
- 모델 SQL은 `SELECT` 한 문장과 승인된 테이블만 허용하고 `SELECT *`를 차단한다.
- 조회 결과에서 검수자 등 운영자 식별 필드를 제거한 뒤 모델에 전달한다.
- JDBC 연결을 읽기 전용으로 지정하고 최대 100행, 기본 5초 제한을 적용한다.
- 실제 DB 계정에도 승인된 테이블별 `SELECT` 권한만 부여한다. 이 DB 권한이 최종 안전장치다.
